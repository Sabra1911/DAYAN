# Teacher Dashboard - Environmental Sciences 🌱

A modern, responsive, serverless dashboard built specifically for teachers in Environmental Sciences and Biology.

## 🚀 Features

- **Class Planner:** Plan theoretical, practical, and experimental classes.
- **Projects Tracker:** Monitor environmental projects (e.g., school gardens) across weeks.
- **Experiment Manager:** Log experiments, required materials, and expected results.
- **Schedule Generator:** Dynamically generate and edit weekly teaching schedules.
- **Student Notes:** Quick tracking of student participation and specific observations.
- **Data Persistence:** 100% local persistence via HTML5 `localStorage`.
- **Backup System:** Export and import capabilities via JSON to prevent data loss.

## 💻 Tech Stack
- **HTML5:** Semantic structuring.
- **CSS3:** Custom CSS variables, Flexbox/Grid, Glassmorphism, CSS Animations. No external frameworks used.
- **Vanilla JavaScript (ES6):** Modular architecture (Module Pattern), Event Delegation, DOM manipulation.

## 📁 Architecture
The project has been refactored for professional maintainability:
- `index.html` - Main markup and layout.
- `css/styles.css` - UI Design and animations.
- `js/app.js` - Application logic structured into specific operational modules (`Planner`, `Schedule`, `StorageManager`, etc.).

## 🔧 Setup & Installation

1. Clone this repository.
2. Open `index.html` directly in any modern web browser. No local server required!
